# Sites Internet Pertinents pour le Projet IA-TSA

## Contexte du projet
Recherche appliquée sur l'usage de l'IA comme outil d'aide pour les personnes atteintes de troubles du spectre autistique (TSA), dans un contexte éducatif avec accès à une salle informatique.

## 💻 Activités Pratiques en Salle Informatique (Cause-Effet / Sensoriel)

Pour TSA non verbal avec troubles moteurs moteurs sévères — activités directement utilisables sans IA, gratuit, navigateur, sans installation.

| Plateforme | URL | Description | Profil |
|-----------|-----|-------------|--------|
| **Shiny Learning – Free Games** | https://www.shinylearning.co.uk/freegames/ | Jeux cause-effet purs (ex: Fireworks = un clic → feu d'artifice). Réaction visuelle/sonore immédiate. Accessible souris, clavier, switch, eye-gaze. | Très grave moteur, attention conjointe |
| **SpecialBites** | http://www.specialbites.com/Easy-Sensory-Games-for-special-needs/ | Jeux mono-switch / cause-effet. Jouable souris, espace, clic. Niveaux progressifs, sans téléchargement. | Débutant, fatigabilité motrice |
| **HelpKidzLearn – Sensory** | https://www.helpkidzlearn.com/sensory-learning/ | Espaces sensoriels interactifs, structurés. Compatible souris/clavier/switch/eye-gaze. 2 semaines gratuites (pas de CB). | Stimulation sensorielle graduée |
| **WonderTree** | https://www.wondertree.co/online-games-for-autism/ | Jeux sensoriels conçus autisme, navigateur, aucun téléchargement. Interface claire, réactions prévisibles. | Prévisibilité + structuration |
| **Little Miss Kim's Class** | https://www.littlemisskimsclass.com/2017/06/free-websites-to-use-with-switches-in.html | Annuaire de sites « switch-accessible » testé en classe spécialisée (France/UK). Point de départ pour exploration. | Ressource de navigation |

> **Principe d'utilisation** : L'accompagnant pilote souris/clavier. L'apprenant indique un choix (regard, geste, vocalise). L'accompagnant confirme l'action → réaction visuelle/sonore immédiate = lien causal. Permet contrôle décisionnel même sans motricité fine.

> **Risque surstimulation** : Profil polyhandicap peut se désengager si trop de stimuli. Coupe le son ou réduis la complexité à la première trace de retrait/agitation.
