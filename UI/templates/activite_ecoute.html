Le jeune écrit, la machine lit à voix haute.

Déroulement

  1. Taper un mot, une lettre ou une suite de lettres dans le champ.
  2. Appuyer sur Entrée ou sur le bouton haut-parleur : le texte est lu à voix haute et s'ajoute à la liste.
  3. Chaque ligne de la liste peut être réécoutée (bouton haut-parleur) ou corrigée (bouton crayon).
  4. En correction : Entrée valide, Échap annule.

Bon à savoir

  • La voix est générée localement sur le poste : rien n'est envoyé sur Internet.
  • Le texte saisi n'est jamais enregistré dans les journaux d'usage.
  • Tout est lisible, y compris les suites de lettres sans signification : c'est utile pour explorer le lien entre lettres et sons.

Si aucune voix ne sort, le modèle vocal n'est pas installé sur ce poste — voir le README du projet.
