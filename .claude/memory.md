## 2026-07-27 — Souris non autonome pour les jeunes
Les jeunes TSA accompagnés dans ce projet ne sont pas autonomes avec la souris. Toute activité ou jeu doit être pilotable intégralement au clavier (ou par contacteur mappé sur une touche) du côté du jeune. Le pointage souris peut rester disponible pour l'accompagnant, jamais comme entrée requise pour le jeune.
